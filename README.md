# 🐺 Wolfie English Kids — Английский для детей от первых слов до B2

Самостоятельное **офлайн-приложение Android** для русскоязычных детей. Основано на архитектуре нашего Wolfie English (Android WebView + нативный Android TextToSpeech + локальные достижения), но содержит **отдельный интерфейс, учебный курс, пакет и хранилище**. Исходный репозиторий `19wolfalone92/English` не меняется.

## Уже работает (v0.1.0)

- **Полный алфавит A–Z**: 26 интерактивных карточек с английскими словами, переводами и озвучиванием.
- 5 ступеней: **Pre-A1 (начало), A1, A2, B1, B2**.
- 30 тематических модулей по 10 занятий — **300 последовательных занятий**.
- **300 вручную написанных англо-русских предложений**, 30 кратких правил, 30 творческих миссий.
- 10 проверяемых заданий на занятие; разные режимы: выбор перевода в обе стороны, слушание через синтез речи, составление предложений из слов, точный ввод фраз на B1/B2.
- 70% правильных ответов открывают следующий урок; бесплатные тренировки любой темы не нарушают прогрессию курса.
- Интервальные повторения: 1, 3, 7, 14, 30 дней; ошибки возвращаются немедленно.
- Большие элементы управления, адаптивный интерфейс, русские подсказки, 10-минутные игровые занятия; при отсутствии английского TTS слушание **не засчитывается** как прослушивание и заменяется обычным переводом.
- Раздел для родителей и сброс прогресса с подтверждением.
- **Без рекламы, аккаунта, аналитики, интернета и опасных социальных функций**. Данные сохраняются в приватном `SharedPreferences`; разрешения Android не требуются.

## Сборка APK

Откройте в GitHub **Actions → Wolfie Kids Android APK → успешный run → Artifacts → `Wolfie-Kids-v0.1.0-debug`**. В ZIP лежит `app-debug.apk`. Нужен Android 7.0+.

Локально требуются JDK 17, Android SDK 35, Gradle 8.9:

```sh
node scripts/test_course.mjs
gradle :app:assembleDebug
```

## Учебная честность и ограничения

**Пройти 300 уроков ≠ получить уровень B2.** Это детский вводный маршрут с практикой, а не полный сертифицированный многолетний курс: для настоящего B2 существенно расширяются чтение, разнообразное аудирование, свободная речь, письмо и независимые оценки. Предложения внутри каждой темы намеренно повторяются в нескольких упражнениях; это **не** 300 уникальных уроков с новыми текстами каждый день. Синтезатор речи телефона не проверяет произношение, а точный ввод не распознаёт все допустимые перефразирования.

Рекомендуемая практика: ребёнку 6–9 лет занятия вместе со взрослым; 10–15 минут в день в начале, без давления. На уровне B1/B2 необходимы дополнительные длинные тексты, разговоры и обратная связь учителя.

## Архитектура

- `app/src/main/assets/content.js` — 30 тематических блоков с уникальными идентификаторами и русскими переводами.
- `app/src/main/assets/app.js` — курс, 300 занятий, 5 типов проверки, интервальное повторение, сохранение, игровое меню.
- `app/src/main/assets/styles.css` — интерфейс для детей с адаптивной вёрсткой и доступными кнопками.
- `app/src/main/java/com/wolfie/kids/MainActivity.java` — безопасная локальная оболочка и озвучивание.
- `scripts/test_course.mjs` — проверка содержания и виртуальный проход первого урока до сохранения результата.
- `.github/workflows/android.yml` — CI-проверки и сборка APK.
