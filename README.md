# 🐺 Eva English Kids — Английский для детей от первых слов до B2

Самостоятельное **офлайн-приложение Android** для русскоязычных детей. Основано на архитектуре нашего Wolfie English (Android WebView + нативный Android TextToSpeech + локальные достижения), но содержит **отдельный интерфейс, учебный курс, пакет и хранилище**. Исходный репозиторий `19wolfalone92/English` не меняется.

## ✅ Eva English Kids 0.9.1 — ребёнок действительно вспоминает слова

Исправлен учебный дефект 0.9.0: на страницах сказки правильная картинка была видна одновременно с вопросом, и ответ можно было выбрать без запоминания. Теперь сначала открывается иллюстрированная страница и английская фраза, затем ребёнок нажимает «Закрыть страничку и вспомнить!». Иллюстрация и текст скрываются, появляется вопрос с двумя картинками. Пока ребёнок не закончил знакомство со страницей, отвечать нельзя. Это **настоящее упражнение на воспоминание**, а не копирование показанного рисунка.

В автоматические тесты добавлена проверка невозможности отвечать до скрытия страницы; две версии APK (основная и отдельная установка Android 13 `com.eva.english.kids.fresh091`) проходят прежние проверки целостности/подписи.

## 🌟 Eva English Kids 0.9.0 — настоящая практика звуков и первые сказки

**Ограничение:** автоматические тесты подтверждают программные сценарии, но не доказывают навыки B2, качество всех переводов и реальную удобную работу на конкретном телефоне. Качественная долгосрочная программа до B2 требует возрастной последовательности, широкого чтения, фонетики с проверенными голосами и независимой оценки устной/письменной речи.

## 🐺 Eva English Kids 0.7.0 — запоминание первых слов и азбука для шестилетней Евы

В ЭТОЙ ВЕРСИИ изменено **само Android-приложение**, а не изображение-макет. Пакет доступен в двух вариантах: обычный и независимая установка Android 13 `com.eva.english.kids.fresh070` (для избежания конфликта debug-подписей с 0.6.0).

**Первые 120 слов — учим с пониманием, а не просто кликаем:** 20 тематических островков. Каждый островок теперь открывает сначала **3 крупных картинки**, затем 3 простых вопроса на узнавание, после чего вторые 3 слова и ещё 3 вопроса. Первые 2 выбора максимально простые. Каждое слово можно слушать повторно через системный английский TTS (если голос установлен), а без голоса предусмотрена видимая подсказка. Неправильные ответы записываются, ребёнок повторяет трудные слова и **повторно узнаёт их по картинке**. Для открытия следующего острова требуется минимум 4 верных ответа из 6 с первого раза; бесконечного начисления звёзд нет.

**«Волшебная память»:** каждое слово хранит число встреч, успешных ответов, этап и дату повторения. Слова повторяются **через 1, 3, 7, 14 и 30 дней**; ошибки попадают на повторение раньше. Отдельная кнопка «Помню слова!» доступна на главном экране. Тренировка ограничена 6–8 словами и не имеет таймеров, наказаний, рейтингов или рекламы.

**Азбука — настоящий курс, а не одна сетка из 26 букв.** Появились **7 маленьких островов букв**: A–D, E–H, I–L, M–P, Q–T, U–X, Y–Z. Каждый показывает большую и строчную букву (A/a), рисунок, английское примерное слово; игра предлагает найти маленькую букву и выбрать слово с заданной начальной буквой. Ошибки объясняются, а пропущенные вопросы возвращаются. Для прохождения нужно 75% с первого раза. Проход по островам, награды и прослушанные буквы сохраняются. Указано, что **название буквы не всегда совпадает с её звуком в словах**; отсутствие точного фонетического тренажёра не выдаётся за полноценный phonics.

**Визуал:** добавлены крупные иллюстрированные карточки для освоения букв, отдельные экраны и кнопки запоминания, мобильный CSS `memory-alphabet.css`. Сохранены 13 цветовых тем и собственная настройка, начальные картинки, сказочная долина, Вулфи и родительский резервный файл прогресса.

**Проверки:** CI прогоняет 20 новых курсов × 6 слов, все 26 букв в 7 группах, хранение истории слов после перезапуска, сценарии ошибок и повторного объяснения, график 1/3/7/14/30 дней, старые 300 уроков, Android Lint, две подписанные сборки APK (обычная и отдельная для Android 13). Автотесты не заменяют испытание на настоящем телефоне или педагогическую экспертизу.

**Уровень B2:** основной маршрут до B2 присутствует, но гарантировать достижение B2 без расширения реальных устных/письменных заданий, слуховых записей и независимых оценок нельзя.

## 📲 Версия 0.5.1 — восстановление установки на Android 13

При диагностике APK предыдущих версий обнаружено, что они подписаны **разными Android Debug сертификатами**, потому что каждый запуск GitHub Actions генерирует новую временную подпись. Поэтому Android отклоняет установку одного APK поверх предыдущей версии с тем же `applicationId`, даже если архив не повреждён. Это известное несоответствие подписей, а не проблема Android 13.

В варианте **0.5.1** изменён только идентификатор установленного Android-приложения на `com.eva.english.kids` и указано полное имя стартовой Activity `com.wolfie.kids.MainActivity`. Так Android может установить новую Еву **рядом со старым Wolfie/Eva**, не требуя её удаления. Сохранённое содержимое старого приложения остаётся на старом месте.

- **Перед установкой:** скачайте настоящий `.apk` из артефакта GitHub или из проверенного прямого файла, не пробуйте установить ZIP как программу. Если ZIP получен через Viber, откройте архив в файловом менеджере и извлеките `app-debug.apk`.
- **Разрешение:** Android 13: «Настройки → Приложения → Специальный доступ → Установка неизвестных приложений», разрешите установку тому приложению, через которое вы открываете APK (Chrome, «Мои файлы» или файловый менеджер). После установки можно выключить это разрешение.
- **Если старая версия уже установлена:** не удаляйте её ради 0.5.1. Новый package ID устанавливается отдельно; его прогресс начинается с нуля. Если в старой версии 0.4.1+ есть прогресс, сделайте «Для родителей → Сохранить прогресс Евы» и потом «Восстановить прогресс из файла» в 0.5.1.
- **После установки:** в Android будут два самостоятельных значка (если старое приложение было установлено). Новое подписано именем «Ева English Kids».
- **Если Android всё ещё не устанавливает:** сохраните точное сообщение установщика («Приложение не установлено», «Пакет недействителен», «Нет разрешения»), так как это разные причины.

**Важно для будущих обновлений:** пакет 0.5.1 решает именно конфликт с предыдущими подписями, но сам по себе не создаёт постоянного ключа. Для регулярных обновлений без повторной установки нужно настроить постоянный приватный release-keystore и хранить его через защищённые GitHub Actions Secrets. Нельзя публиковать приватный ключ прямо в репозитории.

- **Важный функциональный фикс**: исправлена загрузка повреждённых или частично некорректных данных прогресса: безопасные значения по умолчанию, проверка статистики, цветов, наклеек, уроков и дат. Сохранён обратный формат данных.
- **Надёжное сохранение**: Android записывает прогресс синхронно (`SharedPreferences.commit()` в фоне WebView), чтобы уменьшить риск потери недавних ответов при закрытии.
- **Восстановление прерванного занятия**: сохраняются номер урока, следующий вопрос и уже верные ответы. После сворачивания, поворота экрана или перезапуска кнопка «Продолжить занятие» возобновляет незаконченный урок без повторного начисления звёзд.
- **💾 Экспорт и импорт**: в защищённом родительском разделе можно выбрать файл для сохранения или восстановления результатов Евы через стандартный выбор документов Android (Storage Access Framework). Дополнительные разрешения не нужны. Импорт заменяет результаты, поэтому требует подтверждения.
- **Исправленная кнопка Android «Назад»**: закрывает палитру и выходит из упражнения на соответствующий экран, вместо неожиданного завершения приложения.
- **Возвращена работа системных диалогов подтверждения** при удалении и импорте прогресса: WebView теперь использует WebChromeClient.
- **Азбука**: достижение за прослушивание буквы учитывается лишь при доступной озвучке на телефоне; без TTS карточки остаются видимыми.
- **Грамматика**: поправлены женские формы обратной связи Еве в историях и картинках.
- **Автотесты**: интерфейс, 300 уроков с правильными ответами, восстановление прогресса, обработка повреждённых данных, экраны безопасности, проверка Android Lint и сборка APK.
- **Ограничение установки**: v0.4.1 всё ещё отладочная сборка Android, сертификаты из разных GitHub Actions могут не совпадать; перед удалением любой старой версии экспортируйте данные из старой версии, если это возможно (функция экспорта доступна начиная с 0.4.1), либо сначала сохраните данные иным способом. Запуск на физическом Android-устройстве ещё требует отдельной проверки.

## Сборка APK

Откройте в GitHub **Actions → Wolfie Kids Android APK → успешный run → Artifacts → `Eva-English-Kids-v0.5.0-debug`**. В ZIP лежит `app-debug.apk`. Нужен Android 7.0+. **Внимание:** разные GitHub Actions debug APK могут подписываться разными ключами и не устанавливаться поверх предыдущей версии. Не удаляйте установленное приложение с важным прогрессом, не сохранив его вне приложения. Для постоянных обновлений понадобится один и тот же защищённый ключ подписи выпуска.

Локально требуются JDK 17, Android SDK 35, Gradle 8.9:

```sh
node scripts/test_course.mjs
gradle :app:assembleDebug
```

## Учебная честность и ограничения

**Пройти 300 уроков ≠ получить уровень B2.** Это детский вводный маршрут с практикой, а не полный сертифицированный многолетний курс: для настоящего B2 существенно расширяются чтение, разнообразное аудирование, свободная речь, письмо и независимые оценки. Предложения внутри каждой темы намеренно повторяются в нескольких упражнениях; это **не** 300 уникальных уроков с новыми текстами каждый день. Синтезатор речи телефона не проверяет произношение, а точный ввод не распознаёт все допустимые перефразирования.

Рекомендуемая практика: ребёнку 6–9 лет занятия вместе со взрослым; 10–15 минут в день в начале, без давления. На уровне B1/B2 необходимы дополнительные длинные тексты, разговоры и обратная связь учителя.

## Как сменить цвета

Нажмите **🎨 в правом верхнем углу** детского приложения. Выберите одну из шести палитр или два цвета вручную, затем **«🌸 Готово!»**. Текущий урок при смене палитры не сбрасывается. Все изменения сохраняются локально.

Примечание: для произношения на английском и русских голосовых инструкций могут понадобиться системные пакеты синтеза речи Android. Если русского голоса нет, приложение остаётся полностью работоспособным, но русские подсказки могут быть без звука.
